# Registration Checker (রেজিস্ট্রেশন নম্বর যাচাই)

A simple, fast, monochrome, government-notice style web application that allows students to check if their registration number appears in an official exam notice.

## File Structure

```
registration-checker/
├── index.html        # Main HTML layout
├── style.css         # CSS styles (Monochrome / Instrument Sans / JetBrains Mono)
├── script.js         # Search logic & dynamic UI updates
├── registrations.json# Complete dataset extracted from notice
├── package.json      # Node/Serve configuration
└── README.md         # Documentation & instructions
```

## How to Open in VS Code

1. Open VS Code.
2. Click **File > Open Folder** and select the `registration-checker` folder.
3. Install the **Live Server** extension in VS Code.
4. Right-click `index.html` and select **Open with Live Server**.

Alternatively, run in terminal:
```bash
npx serve .
```
